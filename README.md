# University of Layyah — Campus Blog

A responsive front-end website project made with HTML, CSS, and JavaScript.

## Features
- University-style logo on the left side of the header
- Responsive navigation bar with mobile menu
- Hero/welcome section
- Campus blog cards and category filters
- Campus updates / events section
- About section and demo contact form
- JavaScript interactions and responsive styling

## Run locally
1. Download or extract this project.
2. Open `index.html` in a web browser.

## GitHub submission
1. Create a new **public** repository on GitHub, for example `University-of-Layyah-Blog`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository.
3. Open the repository page and copy its URL.
4. Paste that repository URL into your Google Classroom assignment.

## Important
This is a student demonstration project, not an official university website. The logo is a custom text emblem and the post/event content is sample content. Replace sample information with verified university details before publishing.
